# Giddy product site

Commercial launch site for Giddy, the physical tabletop agent created by Otra Mano.

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm test
npm audit
```

The priority-list form opens the public Otra Mano WhatsApp with the visitor's details prefilled. It does not charge or store personal data on the site.
